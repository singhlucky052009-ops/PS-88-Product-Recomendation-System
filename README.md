Project Overview

This project recommends products to customers based on their purchase history.

Objectives

- Store customer purchase data.
- Calculate similarity using Jaccard similarity.
- Find the most similar customer.
- Recommend a product that the customer has not purchased.
- Recommend the most popular product when all similarity scores are zero.

Features

- Stores purchase information in a Python dictionary.
- Displays similarity scores in descending order.
- Displays scores up to two decimal places.
- Handles invalid customer names and empty input.

Requirements

- Python 3
- No external libraries required if the code uses only standard Python libraries.

How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the Python program.
4. Enter a customer name when prompted.
5. Type "exit" to stop the program.
